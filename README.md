# The Little Taco Shop

A small three-page restaurant website built with plain HTML and CSS, one of my first web projects.

## Pages

- [Littleshop.html](Littleshop.html): home page
- [shophours.html](shophours.html): opening hours
- [ContactUs.html](ContactUs.html): contact page

Styles are in [main.css](main.css).

## Run it

No build step: clone the repository and open `Littleshop.html` in a browser.
